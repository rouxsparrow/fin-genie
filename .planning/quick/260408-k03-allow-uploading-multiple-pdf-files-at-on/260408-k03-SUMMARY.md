# Quick Task 260408-k03: Multi-file PDF Upload Summary

Multi-file drag-and-drop upload with queue-based sequential processing through parse-review-import cycle, showing "File N of M" progress indicator.

## What Was Done

### Task 1: Update PdfDropZone to accept multiple files (b889ec2)

- Changed `onFileSelected(file: File)` prop to `onFilesSelected(files: File[])` for compile-time safety on consumer updates
- Removed `maxFiles: 1` from useDropzone config to allow unlimited file selection
- Updated rejection toast to show count for multi-file rejections (`"N file(s) rejected..."`)
- Updated helper text: "Drag PDFs here or click to browse", "Drop PDFs to upload", "Max 4MB each"

### Task 2: Implement multi-file queue state machine (48d4003)

- Replaced `ImportPageState` with queue-aware state: `queue: FileQueueItem[]`, `currentIndex: number`
- `handleFilesSelected`: sorts files alphabetically, builds queue, starts parsing first file
- `advanceToNextFile`: increments index and parses next file, or resets to idle after last file
- `handleSkipFile`: advances to next file without importing (wired to ReviewScreen's `onUploadAnother` for non-last files)
- File queue progress indicator: "File N of M" with progress bar, only shown when queue > 1 file
- Error screen: "Skip & Continue" button appears alongside "Upload Again" when more files remain
- Summary toast: "All N files processed." after completing the last file in a multi-file queue
- `ParseProgress`: added optional `filePosition` prop showing "Parsing file N of M: filename"
- `CollapsedDropZone`: added optional `uploadAnotherLabel` prop (defaults to "Upload another", shows "Skip file" in multi-file queues)
- `ReviewScreen`: passes through `uploadAnotherLabel` prop to `CollapsedDropZone`
