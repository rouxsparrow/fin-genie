# Phase 4 — UI Design Contract

> Visual and interaction contract for the Dashboard & Analytics phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope:** Dashboard page with stat cards, donut chart, bar chart, recent transactions preview, and date range selector. Transactions list page with search, category filter, sortable columns, and server-side pagination. Viewer read-only access to both pages.
>
> **Inherits from:** Phases 1-3 UI-SPEC. All spacing, typography, color, interaction states, and Neo Brutalism styling tokens carry forward. This document only declares additions and phase-specific contracts.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui + neobrutalism registry |
| Preset | Neo Brutalism amber -- `@neobrutalism/*` components via shadcn CLI |
| Component library | Radix UI (via shadcn primitives) |
| Icon library | lucide-react |
| Font | DM Sans (Google Fonts, `next/font/google`) |

**Unchanged from prior phases.** All existing Neo Brutalism components are reused. New dependencies for this phase: `recharts` (3.8.x), `@tanstack/react-table` (8.x), `react-day-picker` (9.x).

## Spacing Scale

Inherited from Phase 1 (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, badge padding, chart legend item gap |
| md | 16px | Default element spacing, card padding, stat card inner gap |
| lg | 24px | Section padding, gap between stat cards and chart row, gap between chart cards |
| xl | 32px | Layout gaps between major page sections (stat row to charts, charts to recent transactions) |
| 2xl | 48px | Page-level vertical padding |
| 3xl | 64px | Not used in Phase 4 |

Exceptions:
- Stat cards use a 16px grid gap on desktop (4-column grid). On mobile, stat cards stack vertically with 16px gap.
- Chart cards have 24px internal padding for Recharts container breathing room.
- Date range selector bar height is 48px with 16px horizontal padding.
- Donut chart inner radius is 60% of outer radius (not a spacing token, a chart config).

## Typography

Inherited from Phase 1. No new roles needed.

| Role | Size | Weight | Line Height | Phase 4 Usage |
|------|------|--------|-------------|---------------|
| Body | 16px | 500 (medium) | 1.5 | Transaction descriptions, chart tooltips body text, stat card labels, date range preset labels |
| Label | 14px | 500 (medium) | 1.4 | Table cells (date, amount, description), column headers use 14px/700, chart legend text, pagination info, search input placeholder, category filter label |
| Heading | 24px | 700 (bold) | 1.2 | Page titles ("Dashboard", "Transactions"), chart card titles ("Spending by Category", "Monthly Spending"), stat card headings |
| Display | 32px | 700 (bold) | 1.1 | Total spending figure in the primary stat card |

**Additional typographic rules for this phase:**
- Stat card primary values (dollar amounts) use `tabular-nums` for alignment across the 4-card row.
- Comparison indicators ("+12% vs last month") use 14px/500 with semantic color (green for decrease, red for increase -- see Color section).
- Chart axis labels use 12px/500 in foreground at 60% opacity. This is the ONLY use of 12px in the project -- it is a Recharts internal label, not a design system size.
- Donut chart center text (total amount) uses 24px/700.

## Color

Inherited from Phase 1. Phase 4 introduces chart palette usage and comparison indicator colors.

| Role | CSS Variable / Value | Usage |
|------|---------------------|-------|
| Dominant (60%) | `--background` / `oklch(96.22% 0.0569 95.61)` | Page background, content area surface |

| Accent (10%) | `--main` / `oklch(84.08% 0.1725 84.2)` | See reserved-for list below |
| Foreground | `--foreground` / `oklch(0% 0 0)` | Body text, headings, icons, table text |
| Border | `--border` / `oklch(0% 0 0)` | All borders (2px solid), box shadows |
| Destructive | inline `#ef4444` | Not used in Phase 4 (no destructive actions) |

### Chart Color Palette

Uses the 5 chart colors declared in `globals.css` (Phase 1). Categories are assigned colors in order of spending amount (highest spender gets `--chart-1`).

| Token | Hex | Usage |
|-------|-----|-------|
| `--chart-1` | #FFBF00 | Highest-spending category in donut + corresponding bar chart highlight |
| `--chart-2` | #0099FF | Second category |
| `--chart-3` | #FF7A05 | Third category |
| `--chart-4` | #00D696 | Fourth category |
| `--chart-5` | #7A83FF | Fifth category |

If more than 5 categories exist, categories 6+ are grouped into an "Other" slice using `--foreground` at 30% opacity (#0000004d).

### Comparison Indicator Colors

| Color | Value | Usage |
|-------|-------|-------|
| Spending decrease (good) | `#16a34a` (Tailwind `green-600`) | Down arrow + percentage text when spending is lower than comparison baseline |
| Spending increase (caution) | `#d97706` (Tailwind `amber-600`) | Up arrow + percentage text when spending is higher than comparison baseline |

These colors are used ONLY on the small comparison text in stat card #1 (Total Spending). They are NOT applied to chart elements, backgrounds, or borders.

### Accent Reserved For (Phase 4 additions)

The amber accent (`--main`) is used on these additional elements in Phase 4:

1. **Active date range preset button** -- amber background on the currently selected preset (e.g., "This Month")
2. **"View All Transactions" link** -- amber underline on hover
3. **Active "Dashboard" and "Transactions" sidebar nav items** -- amber background (inherited pattern)
4. **Category badge in transaction table** -- default Badge variant (amber bg) for category column
5. **Primary chart color (`--chart-1`)** -- amber-adjacent, already declared

Accent is NOT used on: chart backgrounds, table row highlights, pagination buttons, search input, or filter dropdown.

## Page Layouts

**Two states:** Empty (no imported transactions) and Populated (data available).

#### Empty State

Uses the existing EmptyState component (already implemented in current placeholder). Role-aware copy:

- **Admin:** Icon `BarChart3` (48px), heading "No spending data yet", body "Upload your first bank statement to start tracking where your money goes.", CTA "Import Statement" linking to `/import`.
- **Viewer:** Icon `BarChart3` (48px), heading "No spending data yet", body "Ask your admin to import a statement to start viewing spending data.", no CTA button.

#### Populated State Layout

Top-to-bottom vertical stack with these sections:

**1. Page Header Row (flex, space-between)**
- Left: "Dashboard" page heading (24px/700)
- Right: DateRangeSelector component
- 24px gap below

**2. Stat Card Grid (D-01)**
- 4-column CSS grid on desktop (`grid-cols-4`), 16px gap
- 2-column grid on tablet (`md:grid-cols-2`), 16px gap
- 1-column stack on mobile (`grid-cols-1`), 16px gap
- 32px gap below

**3. Charts Row (D-02, D-03)**
- Desktop: 2-column grid (`grid-cols-2`), 24px gap. Left = donut chart card, right = bar chart card.
- Mobile: stacks vertically (1 column), 24px gap between charts.
- 32px gap below

**4. Recent Transactions Preview (D-04)**
- Card wrapping a table of the last 10 transactions within the selected date range
- Card header: "Recent Transactions" (24px/700) + "View All" link (14px/500, amber underline on hover, navigates to `/transactions` preserving date range URL params)
- Table columns: Date | Description | Category | Amount
- Column headers: 14px/700
- Rows: 14px/500, alternating backgrounds
- Below table (if more than 10 transactions exist): text "Showing 10 of {total}" (14px/500, 40% opacity)
- Mobile: stacked cards (same pattern as import review)

### Stat Cards Detail (D-01)

Each stat card is a standard Card component with CardHeader (label) and CardContent (value).

**Card 1: Total Spending**
- Label: "Total Spending" (14px/500, 60% opacity)
- Value: "$X,XXX.XX" (32px/700, `tabular-nums`)
- Comparison line 1: "{arrow} X% vs last month" (14px/500, green-600 if decrease, amber-600 if increase)
- Comparison line 2: "{arrow} X% vs monthly avg" (14px/500, green-600 if decrease, amber-600 if increase)
- Arrow icons: `TrendingDown` (lucide, 14px) for decrease, `TrendingUp` (lucide, 14px) for increase
- If no prior month data for comparison: show "--" instead of percentage

**Card 2: Top Category**
- Label: "Top Category" (14px/500, 60% opacity)
- Value: Category name (24px/700)
- Subtext: "$X,XXX.XX" (16px/500) -- the amount spent in that category

**Card 3: Largest Transaction**
- Label: "Largest Transaction" (14px/500, 60% opacity)
- Value: "$X,XXX.XX" (24px/700, `tabular-nums`)
- Subtext: truncated description (16px/500, max 30 characters with ellipsis)

**Card 4: Recurring Spend**
- Label: "Recurring Spend" (14px/500, 60% opacity)
- Value: "$X,XXX.XX" (24px/700, `tabular-nums`)
- Subtext: "Subscriptions" (16px/500) -- hardcoded to the "Subscriptions" category
- If no "Subscriptions" category exists: value shows "$0.00", subtext shows "No subscriptions category" (14px/500, 40% opacity)

### Category Donut Chart Detail (D-02)

Card title: "Spending by Category" (24px/700) in CardHeader.

**Chart layout (desktop):** Side-by-side. Donut chart on the left (50% width), legend on the right (50% width).
**Chart layout (mobile):** Stacked. Donut chart above, legend below.

**Donut chart (Recharts PieChart):**
- Outer radius: 120px on desktop, 100px on mobile
- Inner radius: 60% of outer (72px desktop, 60px mobile)
- Center label: total spending amount (24px/700)
- Segment stroke: 2px white (`--secondary-background`)
- Segment colors: `--chart-1` through `--chart-5` assigned by descending spend amount. "Other" (6+ categories) uses `--foreground` at 30%.
- No animation on initial load (respects `prefers-reduced-motion` by default)
- Hover: segment slightly expands outward by 4px (activeShape), tooltip appears
- Click: filters dashboard to that category (updates URL param `?category={id}`, all components re-filter)

**Legend (custom, not Recharts Legend):**
- Vertical list of legend items
- Each item: color swatch (12px square, 2px border, rounded-base) + category name (14px/500) + amount (14px/500, right-aligned) + percentage (14px/500, 40% opacity, right-aligned)
- Items sorted by spending amount descending (matches donut slice order)
- 8px gap between legend items
- Clickable: same behavior as clicking the donut segment

**Tooltip (Recharts Tooltip with custom content):**
- White bg (`--secondary-background`), 2px border, rounded-base, 4px shadow (Neo Brutalism style)
- Content: category name (14px/700) + amount (14px/500) + percentage of total (14px/500)
- 8px padding

### Donut Click-to-Filter Interaction (D-02 specific)

When a user clicks a donut segment or legend item:
1. URL param `?category={category_id}` is added
2. Dashboard stat cards recalculate for that category only (Total Spending becomes category total, Top Category card hides, Largest Transaction filters to category)
3. Recent transactions preview filters to that category
4. A "Filtered: {Category Name}" badge appears below the stat cards with an "X" button to clear the filter
5. Navigating to "View All" on `/transactions` preserves the `?category={id}` param
6. Clicking the same segment again (or the X button) clears the filter

**Filter badge styling:**
- Badge component, `variant="default"` (amber), with `X` icon (lucide, 12px) as a clickable close button
- Positioned in a flex row between stat cards and charts with 16px vertical spacing

## Responsive Behavior

Inherits from Phase 1 breakpoint at 768px (Tailwind `md`).

| Breakpoint | Layout Change |
|------------|--------------|
| >= 1024px (lg) | Stat cards 4-column grid. Charts side-by-side 2-column grid. Full table with all columns. |
| >= 768px (md) | Stat cards 2-column grid (2x2). Charts stack vertically. Full table with all columns. Sidebar visible. |
| < 768px | Stat cards 1-column stack. Charts stack vertically. Table transforms to stacked cards. Sidebar hidden (hamburger drawer). Date range selector full-width below heading. |

**Phase 4 mobile specifics:**
- Date range selector wraps below page heading, full width, presets scroll horizontally if they overflow
- Stat cards stack vertically, full width, 16px gap
- Donut chart: legend moves below chart (stacked layout)
- Bar chart: maintains full width, reduces bar count labels if many months

## Accessibility

Inherits all Phase 1-3 accessibility contracts. Phase 4 additions:

| Concern | Implementation |
|---------|---------------|
| Chart keyboard | Donut segments navigable via arrow keys when chart is focused. Enter/Space activates the filter. `role="img"` on chart container with `aria-label="Spending breakdown by category: {summary}"`. |
| Chart screen reader | Hidden table (`sr-only`) with equivalent data below each chart for screen readers. Columns: Category, Amount, Percentage (donut) or Month, Amount (bar). |
| Date range selector | Preset buttons in a `role="group"` with `aria-label="Date range presets"`. Active preset has `aria-pressed="true"`. Calendar popover announces "Select start date" and "Select end date" via `aria-label`. |
| Sort indicators | Sortable column headers have `aria-sort="ascending"`, `aria-sort="descending"`, or `aria-sort="none"`. |
| Pagination | "Previous" and "Next" buttons have `aria-label="Go to previous page"` and `aria-label="Go to next page"`. `aria-disabled="true"` when on first/last page. Live region announces "Page {N} of {M}, showing {count} transactions". |
| Search | Search input has `aria-label="Search transactions by description"`. Results count announced via `aria-live="polite"` region: "{N} transactions found". |
| Category filter | Select has `aria-label="Filter by category"`. |
| Filter badge | Badge has `aria-label="Filtered by {Category Name}. Press to remove filter."`. Close button has `aria-label="Remove category filter"`. |
| Color independence | Chart segments are distinguishable by legend labels, not only color. Comparison indicators use arrows (up/down icons) in addition to color. |
| Stat card values | Dollar amounts use `aria-label` with full text via `Intl.NumberFormat`. |
