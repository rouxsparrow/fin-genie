<objective>
Build the complete PDF upload flow and transaction review screen. Admin uploads a Citibank SG PDF on the /import page, sees parsed transactions in a split categorized/uncategorized review, and can import them to the database.

Purpose: This is the primary user-facing feature of Phase 2 -- the upload-parse-review-import workflow that turns a PDF into structured transaction data.

Output: Server actions for parsing and importing, import page with 5-state UI, all review screen components, and functional import flow.

**D-05 override:** CONTEXT.md D-05 specifies "max 10MB" but Vercel has a hard 4.5MB request body limit for serverless functions (verified in RESEARCH.md sources). Since bank statements are typically 100KB-2MB, a 4MB client-side limit is well within practical needs. This is documented as resolved in RESEARCH.md Open Question 2. If a real statement exceeds 4MB in the future, the mitigation path is uploading to Supabase Storage first, then processing from storage URL.

Create `src/app/actions/import-actions.ts` with two server actions following the established pattern from `user-management.ts`:

**1. `parseStatement(formData: FormData)`:**

```typescript
'use server';

import { extractText, getDocumentProxy } from 'unpdf';
import { createClient } from '@/lib/supabase/server';
import { parseStatementText } from '@/lib/parser/parse-statement';
import { BankFormatConfig, ParseResult, ParseError, ParsedTransaction } from '@/lib/parser/types';

// Return type for parseStatement
interface ParseStatementResult {
  success: true;
  data: ParseResult & { duplicateHashes: string[] };
  fileName: string;
} | {
  success: false;
  error: { code: string; message: string };
}
```

Steps:
1. Verify admin using the same pattern as `verifyAdmin()` in user-management.ts (copy the function or extract into shared util).
2. Extract `File` from FormData via `formData.get('file') as File`. Validate it's a PDF (`file.type === 'application/pdf'`). If not, return error with code `parse_failed` and message `"Invalid file. Please upload a PDF."`.
3. Convert File to `Uint8Array`: `new Uint8Array(await file.arrayBuffer())`.
4. Use unpdf: `const pdf = await getDocumentProxy(buffer); const { text: pageTexts } = await extractText(pdf, { mergePages: false });`.
5. Load bank config from database: `supabase.from('bank_configs').select('config').eq('is_default', true).single()`. Cast config to `BankFormatConfig`.
6. Call `parseStatementText(pageTexts, config)`. If result is a ParseError (check for `code` property), return `{ success: false, error: result }`.
7. Query existing transaction hashes from the `transactions` table for the current household: `supabase.from('transactions').select('transaction_hash').in('transaction_hash', result.transactions.map(t => t.hash))`. Collect into a `duplicateHashes: string[]` array.
8. Return `{ success: true, data: { ...result, duplicateHashes }, fileName: file.name }`.

Wrap the entire function body in try/catch. On any unhandled error, return `{ success: false, error: { code: 'parse_failed', message: 'This PDF could not be read. The file may be damaged or in an unexpected format.' } }`.

**2. `importTransactions(data: { transactions: ParsedTransaction[]; statementPeriodStart: string; statementPeriodEnd: string; fileName: string })`:**

Steps:
1. Verify admin (same pattern).
2. Get user's profile to access `household_id`.
3. Create import record: `supabase.from('imports').insert({ household_id: profile.household_id, file_name: data.fileName, statement_period_start: data.statementPeriodStart, statement_period_end: data.statementPeriodEnd, transaction_count: data.transactions.length, imported_by: userId }).select().single()`.
4. Insert transactions: `supabase.from('transactions').insert(data.transactions.map(t => ({ household_id: profile.household_id, import_id: importRecord.id, transaction_date: t.date, description: t.description, amount_cents: t.amountCents, is_debit: t.isDebit, transaction_hash: t.hash })))`. Use `.select()` to get inserted rows.
5. If any insert fails (e.g., duplicate hash constraint violation), return `{ success: false, error: 'Import failed. Please try again.' }`.
6. Call `revalidatePath('/import/history')`.
7. Return `{ success: true, importId: importRecord.id, transactionCount: data.transactions.length, period: \`${data.statementPeriodStart} to ${data.statementPeriodEnd}\` }`.
