**1. Create `src/lib/parser/types.ts`:**

```typescript
export interface BankFormatConfig {
  statement_period: {
    pattern: string;       // Regex to find statement period text
    date_format: string;   // e.g., "dd/MM/yyyy" or "dd MMM yyyy"
  };
  transaction: {
    line_pattern: string;          // Regex with capture groups for date, desc, amount
    date_format: string;           // e.g., "dd MMM" (no year in Citibank SG)
    credit_indicator: 'parentheses' | 'negative' | 'column';
    description_continuation: boolean;
  };
  skip_patterns: string[];         // Lines to ignore (headers, subtotals, noise)
  section_markers?: {
    start?: string;                // Pattern marking start of transaction section
    end?: string;                  // Pattern marking end of transaction section
  };
}

export interface ParsedTransaction {
  date: string;            // ISO date string (YYYY-MM-DD)
  description: string;
  amountCents: number;     // Always positive, stored as integer cents
  isDebit: boolean;        // true = purchase, false = credit/refund
  hash: string;            // SHA-256 of date|description|amountCents|isDebit
}

export interface ParseResult {
  transactions: ParsedTransaction[];
  statementPeriodStart: string;  // ISO date (YYYY-MM-DD)
  statementPeriodEnd: string;    // ISO date (YYYY-MM-DD)
  totalPages: number;
}

export interface ParseError {
  code: 'unsupported_format' | 'no_transactions' | 'parse_failed';
  message: string;
}
```

**2. Create `src/lib/parser/hash.ts`:**

```typescript
import { createHash } from 'crypto';

export function computeTransactionHash(
  date: string,
  description: string,
  amountCents: number,
  isDebit: boolean
): string {
  const input = `${date}|${description}|${amountCents}|${isDebit}`;
  return createHash('sha256').update(input).digest('hex');
}
```

**3. Create `src/lib/parser/parse-statement.ts`:**

Export three functions:
- `parseAmount(raw: string): { amountCents: number; isDebit: boolean }` -- strips parentheses (credit indicator), strips commas, parseFloat, Math.round(value * 100). Throws on NaN or negative.
- `inferTransactionDate(dateStr: string, periodStart: Date, periodEnd: Date): Date` -- uses date-fns `parse` to try both start year and end year, returns the one that falls within the interval via `isWithinInterval`. Fallback to end year.
- `parseStatementText(pageTexts: string[], config: BankFormatConfig): ParseResult | ParseError` -- pure function:
  1. Concatenate all page texts into lines array
  2. Extract statement period using `config.statement_period.pattern` regex. If not found, return ParseError with code 'unsupported_format'.
  3. Parse period dates using date-fns `parse` with `config.statement_period.date_format`.
  4. Find section boundaries using `config.section_markers.start` and `config.section_markers.end` if provided. Process lines between markers (or all lines if no markers).
  5. For each line within section: skip if matches any `config.skip_patterns`. Try matching against `config.transaction.line_pattern` regex. If match, extract date (group 1), description (group 2), amount (group 3). Parse amount with `parseAmount`. Infer full date with `inferTransactionDate`. Compute hash with `computeTransactionHash`.
  6. If `config.transaction.description_continuation` is true, and the NEXT line does NOT match the transaction pattern AND does NOT match any skip pattern, trim it and append to the current transaction's description (separated by a space). Skip that line on next iteration.
  7. If no transactions found, return ParseError with code 'no_transactions'.
  8. Return ParseResult with transactions array, period start/end as ISO strings, and totalPages = pageTexts.length.

Import date-fns functions: `parse`, `isWithinInterval`, `format`.
