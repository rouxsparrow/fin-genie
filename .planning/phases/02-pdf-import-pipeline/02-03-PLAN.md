**1. Create `src/app/(authenticated)/import/history/page.tsx`** as a server component:

```typescript
import { createClient } from '@/lib/supabase/server';
import { FileText } from 'lucide-react';
import { EmptyState } from '@/components/empty-state';
import { ImportHistoryTable } from '@/components/history/import-history-table';
import { TimelineBar } from '@/components/history/timeline-bar';

export default async function ImportHistoryPage() {
  const supabase = await createClient();

  // Fetch imports with profile info for "Imported By"
  const { data: imports } = await supabase
    .from('imports')
    .select('*, profiles!imported_by(full_name)')
    .order('created_at', { ascending: false });

  if (!imports || imports.length === 0) {
    return (
      <div className="p-6 md:p-8">
        <h1 className="text-2xl font-bold">Import History</h1>
        <div className="h-8" />
        <EmptyState
          icon={FileText}
          heading="No imports yet"
          body="Upload your first bank statement to start tracking your spending."
          ctaLabel="Import Statement"
          ctaHref="/import"
        />
      </div>
    );
  }

  return (
    <div className="p-4 md:p-8">
      <h1 className="text-2xl font-bold">Import History</h1>
      <div className="h-4" />
      <TimelineBar imports={imports} />
      <div className="h-6" />
      <ImportHistoryTable imports={imports} />
    </div>
  );
}
```

Note on the join: The `imports` table has `imported_by UUID REFERENCES auth.users(id)`. To get the importer's name, join to `profiles` via `imported_by`. The Supabase select syntax is `profiles!imported_by(full_name)` which creates a foreign key join. If the foreign key relation name doesn't match, use the raw query approach: fetch imports, then separately fetch profiles by IDs.

Implementation:
1. **Compute month range:** Find earliest `statement_period_start` and latest `statement_period_end` across all imports. If fewer than 3 months of data, show minimum 6 month segments for visual context. Range extends to current month.
2. **Compute covered months:** For each import, determine which months (YYYY-MM) it covers (using date-fns `eachMonthOfInterval`, `startOfMonth`, `format`). Build a `Map<string, { count: number }>` where key is "YYYY-MM" and count is total transactions for that month.
3. **Generate segments:** For each month from earliest to current:
   - **Filled** (month has import data): `bg-[#16a34a]` (green-600), white text
   - **Gap** (month in range but no data): `bg-[#ef4444]/20` (red-500 at 20% opacity), black text
   - **Future** (month after current): `bg-secondary-background`, 40% opacity text
4. **Render:**

```tsx
<div className="bg-secondary-background border-2 border-border rounded-base p-4">
  <h3 className="text-sm font-bold">Statement Coverage</h3>
  <div className="h-2" />
  <div className="flex flex-wrap gap-0.5" role="group" aria-label="Statement coverage timeline">
    {segments.map((segment) => (
      <TooltipProvider key={segment.key}>
        <Tooltip>
          <TooltipTrigger asChild>
            <div
              role="img"
              aria-label={`${segment.label}: ${segment.tooltip}`}
              className={cn(
                'h-8 flex-1 min-w-[40px] flex items-center justify-center text-sm font-medium border border-border first:rounded-l-base last:rounded-r-base',
                segment.status === 'filled' && 'bg-[#16a34a] text-white',
                segment.status === 'gap' && 'bg-[#ef4444]/20 text-foreground',
                segment.status === 'future' && 'bg-secondary-background text-foreground/40',
              )}
            >
              {segment.shortLabel}
            </div>
          </TooltipTrigger>
          <TooltipContent>{segment.tooltip}</TooltipContent>
        </Tooltip>
      </TooltipProvider>
    ))}
  </div>
</div>
```

Month label: abbreviated month, add year for January or first visible month (e.g., "Mar", "Jan 26"). Use `format(date, 'MMM')` and conditionally append `format(date, ' yy')` for January or first segment.

Tooltip text:
- Filled: "{Month Year}: {N} transactions imported"
- Gap: "{Month Year}: No data"
- Future: "{Month Year}: Future"

Mobile: bar wraps naturally with `flex-wrap`. If more than 6 months, segments will wrap to multiple rows.
