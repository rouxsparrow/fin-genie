The `config` field is JSONB. Parse it and display key-value pairs:

```tsx
function ConfigDisplay({ config }: { config: Record<string, unknown> }) {
  // Flatten the nested config into displayable key-value pairs
  const entries = flattenConfig(config);

  return (
    <dl className="grid grid-cols-1 gap-3">
      {entries.map(([key, value]) => (
        <div key={key}>
          <dt className="text-sm font-bold">{formatConfigKey(key)}</dt>
          <dd className="text-sm font-medium font-mono break-all">
            {typeof value === 'string' ? value : JSON.stringify(value)}
          </dd>
        </div>
      ))}
    </dl>
  );
}
```

Helper `flattenConfig(obj, prefix)`: recursively flatten nested objects into `["statement_period.pattern", "\\s+Period..."]` pairs. For arrays (like `skip_patterns`), display as comma-separated or as a multi-line list.

Helper `formatConfigKey(key)`: convert snake_case dotted paths to human-readable labels. Examples:
- "statement_period.pattern" -> "Statement Period Pattern"
- "transaction.credit_indicator" -> "Transaction Credit Indicator"
- "skip_patterns" -> "Skip Patterns"

Use `font-mono` for values that look like regex patterns (contain `\\`, `*`, `+`, `[`, `]`, `^`, `$`).

Also display metadata fields from the bank_configs row itself:
- Bank Name: config.bank_name
- Country: config.country_code
- Statement Type: config.statement_type
- Default: config.is_default ? "Yes" : "No"

No edit controls per D-18 (read-only in v1).
