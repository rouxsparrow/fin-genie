## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client-side rule evaluation -> Server import | Category assignments computed client-side are passed to server. Server should not blindly trust them. |
| PopoverContent user input -> Server action | Pattern and category ID from popover cross trust boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | import-actions.ts categoryMap | accept | Client sends categoryMap (hash->categoryId). A malicious client could send arbitrary categoryIds, but (a) categoryId references categories table with FK constraint, (b) only admins can import, (c) re-categorize can fix any incorrect assignments.
